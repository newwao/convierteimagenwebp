Guía de uso

  1. Abre tus imágenes. Selecciona o arrastra archivos JPG, PNG o WebP. Usa «+ Agregar» para ampliar el lote.
  2. Copia y pega. Copia una imagen o una captura y pulsa Ctrl + V (⌘ + V en Mac), o «Pegar imagen». Copia la imagen, no solo su enlace. Si estás escribiendo en un campo de texto, haz clic fuera antes de pegar.
  3. Revisa la imagen completa. Cada imagen se abre ajustada al visor. Usa + y − para acercar o alejar, y «Ajustar» para verla completa. El porcentaje indica la escala real respecto al original.
  4. Optimiza. Elige WebP, JPEG o PNG y ajusta la calidad. PNG no usa el control de calidad. Activa «Redimensionar» si deseas reducir las dimensiones. JPEG no conserva transparencia: elige un fondo blanco o negro.
  5. Compara y gira. Mueve el separador para comparar original y resultado. Usa las flechas de giro para rotar 90°. La vista previa automática refleja tus ajustes.
  6. Organiza los nombres. Conserva el nombre original, usa uno común o reemplaza texto. Puedes añadir prefijo, sufijo y numeración. Desmarca la numeración si no la necesitas.
  7. Convierte y descarga. Pulsa «Convertir» y «Descargar» para una imagen; «Convertir todas» y «Descargar ZIP» para el lote. «Copiar imagen» copia el resultado convertido, o el original si aún no lo convertiste, en PNG para pegarlo en otras aplicaciones.
  8. Guarda tus ajustes. «Guardar actual» crea un preset en este navegador. «Limpiar» quita el lote; no borra tus archivos originales.

El procesamiento es local. Los botones del portapapeles requieren un navegador compatible y HTTPS o localhost, y pueden pedir permiso. Si «Pegar imagen» no está disponible, prueba Ctrl + V o selecciona el archivo. Para conservar el formato WebP/JPEG, usa «Descargar».
